# SSS Chattogram-02 Zone Employee Portal — ডেস্কটপ অ্যাপ

## যেকোনো কম্পিউটারে ইনস্টল করার উপায়

### ১) শুধু ব্যবহার করতে চাইলে (রেডিমেড ইনস্টলার)
| সিস্টেম | ফাইল | কীভাবে চালাবেন |
|---|---|---|
| Windows | `SSS CTG-02 Portal Setup 1.0.0.exe` | ডাবল-ক্লিক করে Next → Install |
| Windows (ইনস্টল ছাড়া) | `SSS CTG-02 Portal 1.0.0.exe` (portable) | সরাসরি ডাবল-ক্লিক |
| Mac | `.dmg` | খুলে অ্যাপটি Applications-এ টেনে আনুন |
| Linux | `.AppImage` | `chmod +x` করে ডাবল-ক্লিক, অথবা `.deb` ইনস্টল |

ইনস্টলার বানাতে **GitHub-এ কোড আপলোড করে** Actions ট্যাবে "Build installers" রান করুন
(Windows, Mac, Linux — তিনটির ফাইল একসাথে পাবেন)।

### ২) নিজের কম্পিউটারে বানাতে চাইলে
1. [Node.js](https://nodejs.org) (LTS) ইনস্টল করুন
2. প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে: `npm install`
3. পরীক্ষা করতে: `npm run desktop`
4. ইনস্টলার বানাতে (নিজের সিস্টেমের জন্য): `npm run dist`
   - শুধু Windows: `npm run dist:win` (Windows কম্পিউটারে চালানো ভালো)
   - শুধু Mac: `npm run dist:mac` (Mac-এই চালাতে হবে)
   - ফলাফল `release/` ফোল্ডারে

  ডেটা সরাতে **সেটিংস → এক্সপোর্ট/ইমপোর্ট** ব্যবহার করুন। নিয়মিত ব্যাকআপ নিন।
- অ্যাডমিন পাসওয়ার্ড ডিফল্ট `admin123` — সেটিংস থেকে বদলে নিন।
